查看跨系统联动关系
  • 循环：心率 / 容量 / 收缩力 → 每搏量与心输出量 → 压力及供氧 → 有限交感代偿。
  • 呼吸：频率 × 有效呼吸深度 → CO₂ / 氧分压 → pH / 意识 → 呼吸代偿；镇静与脑干低供氧可抑制代偿。
  • 肾脏：灌注下降 → 少尿、滤过下降 → 钾与药物清除减慢 → 心肌与循环进一步受影响。
  • 失血：凝血 / 血小板功能异常 → 持续失血 → 容量与血红蛋白下降 → 泵血和携氧同时减少。
  • 肝脏：毒性 / 低灌注 → 损伤 → 药物与乳酸清除、凝血、葡萄糖维持受影响。
  • 代谢：进食 / 药物 → 血糖；低糖影响脑功能，高糖增加渗透性利尿；发热与疼痛增加耗氧。
  • 酸碱与电解质：乳酸 / 肾酸负担 / CO₂ → pH → 呼吸、血钾分布与心肌功能；钾镁钙影响电活动。
  • 损伤：持续缺氧 / 低灌注 → 器官损伤累积 → 功能和代偿能力下降，形成进一步恶化的反馈。

BEHIND THE SIMULATION

理解身体，也理解模型的边界。

一个可解释的生理学沙盒。每一次变化，都由时间、暴露与系统反馈共同推动。

选择干预→吸收 / 清除→系统响应→体征与症状

时间是真正的变量

药物通过一级吸收和清除进入效应室；重复投放会累积。时间倍率只加快模拟时钟，心肺动作仍按当前体征的真实频率播放。

系统彼此联系

低容量改变灌注，低通气改变 CO₂，电解质影响电生理。症状由当前参数触发，而非药物名称直接触发。

数据有明确的边界

通用药名与部分作用方向有公开资料支持；所有剂量响应、时间常数、风险分数与波形均为教学近似，未进行临床校准。
